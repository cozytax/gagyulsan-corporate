# 가결산 리포트 (웹) — 법인용

손익계산서 PDF를 올리면 **12개월 환산 → 3개년 추이 → 세무 진단·관리계획 → A4 2장 보고서(표지 옵션 시 3장)** 를 만들어 PDF로 저장하는 프로그램입니다.
**법인용 확장(2026-11-01):** 재무상태표 PDF를 함께 올리면 **Ⅲ 재무비율 현황** 1장이 추가됩니다(아래 "재무비율 현황" 절). 원본(cozytax/gagyulsan)과 별도 저장소(cozytax/gagyulsan-corporate)입니다.
서버가 필요 없는 정적 웹페이지라서 폴더째 공유 드라이브에 두고 `index.html` 을 열기만 하면 됩니다.

## 배포 (직원 공유)

- **링크로 쓰기**: `배포방법.md` 를 보고 GitHub Pages(무료)나 Netlify 에 올리면 `https://…` 링크가 생깁니다. 올릴 때 `sample/` 폴더(거래처 자료)는 제외.
- **링크 없이**: 이 폴더 전체를 공유 OneDrive 폴더에 두고 각자 `index.html` 을 Chrome/Edge 로 더블클릭.
- 인터넷 연결 필요(글꼴·PDF 라이브러리를 CDN에서 받음). 외부인 차단이 필요하면 `js/config.js` 의 `accessCode` 에 암호 입력.

## 사용 순서

1. **PDF 올리기** — 올해(가결산) 손익계산서를 올립니다. 비교식(당기·전기 2열) 양식이면 한 파일로 2개년이 읽힙니다.
   작년·재작년 파일을 더 올리면 최대 3개년을 비교합니다. 같은 연도가 겹치면 그 연도 파일의 '당기' 열을 우선합니다.
2. **보고서 정보** — 회사명(PDF에서 자동), 업종(선택, 비용 분석 중점 항목이 바뀜), 세무사무소, 담당자(**필수**, 입력하면 그 PC 브라우저에 기억됨), 보고일, 제목, 표지 포함 여부.
3. **예상 세액 설정** — 법인/개인(자동 감지), 공제·감면, 이월결손금. 표시되는 값은 **기본세율 기준 예상 산출세액**이며 기납부세액은 빼지 않습니다(최종 납부세액이 아님).
4. **추가 비용 시뮬레이션** — 항목·유형·지출 예정액을 넣으면 유형별로 **비용 인정 예상액**이 자동 계산됩니다(수정 가능). 개인사업자 본인 급여는 0원, 자산 구입은 기본 20%. **검토 완료**로 바꾼 항목만 예상 세액에 반영되고, 검토 필요 항목은 보고서에 "검토 중"으로만 표시됩니다.
5. **담당자 종합 의견** — 종합 의견 / 중점 검토사항 / 향후 관리계획 세 칸(또는 자유 입력). 비운 칸은 출력되지 않습니다. 2쪽 상단에 강조 상자로 들어갑니다.
6. **연말 확인사항·관리계획** — 거래처 수치에 맞춰 자동 생성되며, 텍스트를 고치거나 지울 수 있습니다(한 줄 = 한 항목, `| 기한`). "자동으로 되돌리기"로 복구.
7. **읽어낸 숫자 확인** — 노란 칸 = 손으로 고친 값, 회색 기울임 = PDF에 없어 계산한 값, 빨간 '미인식' = PDF에서 못 읽은 값(0으로 계산 중). 합계 불일치·필수 항목 누락은 상단 경고로 표시됩니다.
8. **PDF 저장 / 인쇄** — 출력 전 확인 창(회사·기간·설정·경고 요약)이 뜹니다. 인쇄창에서 **"PDF로 저장"**, 여백 **없음**, **배경 그래픽 켜기**.

## 재무비율 현황 (법인용)

- **올리는 법**: 1번 칸에 손익계산서와 재무상태표 PDF를 같이 올립니다(문서 종류는 자동 판별, 파일 목록에 `재무상태표`·`손익계산서` 태그). **세무프로그램 "재무제표 일괄출력"(재무상태표+손익계산서+이익잉여금처분계산서 한 파일)**을 그대로 올려도 쪽마다 서류를 나눠 읽습니다(이익잉여금처분계산서는 건너뜀). 작년 일괄출력 + 올해 가결산 일괄출력 두 파일이면 3개년 손익·재무상태표가 모두 들어옵니다. 법인세 신고서(세무조정계산서) 일괄출력은 지원하지 않습니다. 재무상태표만 올리면 Ⅲ쪽만 만들어지고, 손익이 필요한 지표(이익률·ROA·ROE·회전율·이자보상비율·매출액증가율)는 "손익계산서 필요"로 표시됩니다.
- **업종평균 비교**: 2번 칸 **비교 업종**(한국은행 기업경영분석 업종 분류)과 **기업규모**(중소기업/종합/대기업)를 고르면 지표마다 업종평균과 **양호/보통/미흡** 평가가 붙습니다. 고르지 않으면 비율만 표시. 세분류에 자료가 없으면 상위 업종 평균을 쓰고 `†` 표시.
- **업종평균 자료**: `js/industry_avg.js` — 사무소 엑셀 "(주)_재무현황 보고서.xlsx"의 회전율·성장성·분위·이외 비율 시트에서 이관(한국은행 기업경영분석 2023년 형식, **출처·연도 확인 필요**). ROE 업종평균은 자료에 없어 "비교 없음". 다시 만들 때는 엑셀을 고친 뒤 생성 스크립트(gen_industry.py, 세션 기록)로 재생성.
- **지표 정의**(한국은행 방식, `js/config.js` `ratioGroups`): 부채비율=부채총계/자본총계, 차입금의존도=차입금(단기·장기차입금·유동성장기부채·사채·주임종차입금)/자산총계, 유동비율=유동자산/유동부채, 이자보상비율=영업이익/이자비용(배), 매출액순이익률·영업이익률, ROA=당기순이익/자산총계, ROE=당기순이익/자본총계, 증가율 4종=전기 대비, 회전율 4종=매출액/(자산총계·재고자산·매출채권·매입채무). 손익 항목은 가결산이면 12개월 환산값, 분모는 전기가 있으면 기초·기말 평균잔액(`turnoverUseAverage`).
- **평가 기준**(`js/config.js` `ratioBands`): 업종평균 대비 비율·회전율 ±10%, 이익률·ROA·ROE ±1%p, 증가율 ±3%p, 이자보상비율 ±1배 이내면 보통. 자본잠식(자본총계 ≤ 0)이면 부채비율·ROE는 계산하지 않고 "자본잠식"으로 표시.
- **읽어낸 숫자 확인**: 7번 칸 아래에 재무상태표 표가 따로 생깁니다(대분류 19개 + 비율용 세부 합계). 값을 고치면 빠진 합계는 다시 계산. "재무상태표 연도 추가"로 직접 입력도 가능.
- **대분류가 안 읽히는 양식**: 세부 계정(보통예금·외상매출금·미지급금…)만 텍스트로 남은 PDF는 계정명 분류표(`bsDetailMap`)로 합계를 **추정**하고 경고를 띄웁니다. 반드시 원본과 대조하세요.
- **전기 열·대체 지표**: 전기 재무상태표가 있으면 비율표에 전기 열이 붙습니다(전전기가 없으면 전기 증가율은 '-'). 재고가 없는 회사는 재고자산회전율 대신 비유동자산회전율을 표시합니다.
- **상각 전 영업이익(EBITDA)**: 판관비에 감가상각비·무형자산상각비(`depreciationKeywords`)가 있으면 손익계산서 요약표에 '상각 전 영업이익' 행과 용어 설명이 추가됩니다. 개발비 상각이 큰 회사의 영업손실을 설명할 때 씁니다.
- **글꼴 미내장 PDF**: 일괄출력 일부 쪽은 한글 글꼴이 내장되지 않고 CMap(UniKS-UCS2-H)만 참조해서, pdf.js에 CMap 경로(jsdelivr pdfjs-dist 3.11.174)를 지정해 읽습니다. 인터넷이 끊기면 그 쪽은 빈 쪽으로 처리됩니다.
- **손실 부호**: 손익계산서에서 계정명이 `영업손실`·`당기순손실` 등으로 찍힌 금액은 부호를 뒤집어 읽습니다(세무프로그램은 손실이면 계정명을 바꾸고 양수로 찍고, 같은 줄 전기가 이익이면 음수로 찍음). 2026-11-01 법인용에서 고친 것으로, 원본 gagyulsan 에는 아직 반영되지 않음.

## 12개월 환산 방식

가장 최근 연도의 실적 개월 수(예: 1~9월 = 9개월)를 회계기간 문구에서 읽어 `12 ÷ 개월수` 를 곱합니다(단순 비례).
개월 수가 잘못 읽혔으면 "읽어낸 숫자 확인" 표 맨 아래 **실적 개월 수** 칸에서 고치면 됩니다.

## 지원하는 PDF

- 세무프로그램(더존·세무사랑 등)에서 출력한 **텍스트가 살아있는** 손익계산서 PDF. 스캔 이미지 PDF는 읽지 못합니다.
- 계정명이 "매 출 액" 처럼 띄어져 있어도, 숫자가 한 글자씩 쪼개져 있어도 인식합니다.
- 대분류(Ⅰ.매출액 ~ Ⅹ.당기순이익)와 판관비 세부 항목을 읽습니다. 총이익·영업이익 등이 빠져 있으면 자동 계산합니다.
- 회계기간은 "제N(당)기 YYYY년 M월 D일부터 YYYY년 M월 D일까지" 문구로 읽습니다.

## 유의사항

- 세율표는 `js/config.js` 의 `taxTables` 에 **귀속연도별**로 있습니다(2025: 법인 9/19/21/24%, 2026: 법인 10/20/22/25%, 소득세 6~45% 동일). 기준연도에 맞는 표를 자동으로 고르며, 세법 개정 시 연도를 추가하세요.
- 예상 세액은 기본세율 기준 **산출세액**입니다. 세무조정·다른 종합소득·기납부세액은 반영하지 않으며, 보고서에도 그렇게 표시됩니다.
- 테스트용으로 `index.html?load=sample/파일명.pdf` 처럼 주소에 붙이면 해당 PDF를 자동으로 불러옵니다(쉼표로 여러 개: `?load=sample/a.pdf,sample/b.pdf`).
- css/js 를 고쳐서 다시 올릴 때는 `index.html` 의 `?v=3` 숫자를 하나 올리세요(직원 브라우저가 옛 파일을 캐시하지 않도록).

## 담당자 코멘트

5번 칸에 코멘트를 쓰면 보고서 3쪽 예상 세금 표 아래(면책 문구 위)에 '담당자 코멘트' 상자로 들어갑니다. 줄바꿈 그대로 출력되고, 비우거나 '없음'을 고르면 상자 없이 기존처럼 출력됩니다.

## 추가 비용 시뮬레이션

4번 칸에 올해 안에 추가로 반영할 비용(대표 급여, 퇴직연금, 비품 구입 등)을 항목별로 넣으면, 보고서의 예상 세금 표가 **반영 전 / 반영 후 / 차이** 비교표로 바뀌고 절세 효과 상자와 진단 포인트가 함께 들어갑니다. 추가 비용은 12개월 환산 세전이익에서 그대로 뺍니다(환산하지 않음).
